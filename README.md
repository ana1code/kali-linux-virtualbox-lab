# Kali Linux VirtualBox Lab

Hands-on cybersecurity lab documenting the installation and configuration of **Kali Linux** in a **VirtualBox** virtual machine.

## 🎯 Project Overview

This project documents the practical installation of Kali Linux as a virtual machine using VirtualBox.

The objective was to build a controlled cybersecurity laboratory environment and become familiar with the deployment and initial configuration of a security-focused Linux distribution.

## 🛠️ Technologies & Tools

* Kali Linux
* VirtualBox
* 7-Zip
* Linux
* Virtual Machines

## 💻 Environment

* **Operating System:** Kali Linux
* **Architecture:** 64-bit
* **Virtualization:** Oracle VirtualBox
* **Installation type:** Pre-built virtual machine
* **Kali Linux version:** 2024.3

## 🚀 Installation Process

The installation process included:

1. Downloading Kali Linux from the official website.
2. Selecting the VirtualBox image.
3. Extracting the downloaded `.7z` archive.
4. Creating a new virtual machine in VirtualBox.
5. Configuring the virtual machine hardware.
6. Attaching the existing Kali Linux virtual disk.
7. Starting the virtual machine.
8. Accessing the Kali Linux environment.
